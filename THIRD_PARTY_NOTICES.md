# Data and code licence review

Official original data: Wang and colleagues, Multi-environment field trials for wheat yield, stability and breeding progress in Germany, Figshare v1, https://doi.org/10.6084/m9.figshare.27910269.v1. The version-specific API was rechecked on 28 October 2026 and identifies CC BY 4.0, https://creativecommons.org/licenses/by/4.0/. File ID 50832927, size, MD5 and SHA256 remain in provenance/Figshare_v1_Lock.json. The lean repository excludes the archive, extracted data and author-repository source snapshots; a real locked acquisition tool obtains them on demand. Derived cohorts, restored labels, predictions and result tables are identified as reanalysis changes and must retain attribution without implying endorsement.

External audit-only dataset: Holst, Niels, Data from 56 fungicide trials in wheat fields across Europe 2017–2019, https://doi.org/10.5281/zenodo.6521175, CC BY 4.0. Its small text file remains necessary for the real Phase 1 feasibility audit; it never entered BRIWECS model cohorts. Its original grant is not claimed as funding for this reanalysis.

Third-party code: BRIWECS_Data_Publication and Scientific_Data_Analyis are acquired at recorded fixed commits. Their original MIT notices and stated copyright holder are retained under third_party_licences; source trees are not bundled. Those notices are limited to those repositories and do not assign a licence to original reanalysis code or replace scientific-data attribution.

Original reanalysis and closure code: actual Python analysis scripts, accepted R drawing scripts, new acquisition/verification adapters and documentation are listed separately in FILE_OWNERSHIP.csv. Authorship/rights holders and a public-distribution licence await author confirmation. No MIT, GPL or other blanket code licence was selected. LICENSE_PENDING.md is retained. This candidate is not authorised for public release. Author identities, affiliations, contributions, funding, conflicts, all-author approval, AI tool/model versions/dates and public code address/DOI remain separately pending. No release, DOI creation or journal submission occurred.
